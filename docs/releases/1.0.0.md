# SYNESTRA 1.0.0

First stable Windows x64 release: local MP3 playback with Classic Lightflow, Pearl, Spectrum and ten curated MilkDrop presets.

## Install and launch

Download SYNESTRA-1.0.0-windows-x64.zip from https://github.com/archer266/SYNESTRA/releases/tag/v1.0.0. Extract ALL files into a writable folder, then double-click SYNESTRA.exe. Keep its resources, DLLs and other bundled files together. Node.js, npm and developer tools are not required. Windows 10/11 x64; WebGL2-capable graphics recommended. This unsigned build may show an unknown-publisher/SmartScreen prompt; verify its origin and SHA-256 checksum before choosing to run it.

Import music, select a queue entry or press Play. Use the header to switch visuals; Tune selects MilkDrop presets, blending/cycling and quality settings. Enter fullscreen expands the visual stage. Volume/mute does not weaken visual analysis. Relaunch restores the library and valid visual settings without autoplay. Music stays in its original location.

## Update and uninstall

Extract updates into a new folder; do not overwrite a running application. Close SYNESTRA before deleting its extracted folder to uninstall. Library references/preferences remain in %APPDATA%\SYNESTRA. Optionally delete that app-data folder to reset them (it also removes visual preferences); your source music is not deleted. This ZIP edition needs no installer or administrator rights and creates no uninstaller. It stores settings in AppData rather than beside the executable.

## Release highlights

- MP3 import, persistent library/queue references, seek, volume, shuffle and repeat.
- Classic light trails, translucent Pearl, Linear/Radial Spectrum, and ten distinct MilkDrop compositions with smooth transitions.
- Preset identity in the stage/diagnostics; quiet feedback and highlight refinements.
- Shared pre-output-gain analysis, bounded quality/resolution settings, fullscreen and graphics fallback/retry.

## Known limitations

- Unsigned Windows x64 build; no auto-update service or file associations.
- Clean-machine/another-PC testing, prolonged listening, mixed-DPI and sustained physical 4K/60 FPS remain pending. Actual 3840x2160 buffers were tested on an RX 6800 XT; that is not a universal performance guarantee.
- MilkDrop uses resampled 8-bit mono visual input; some legacy feedback equations remain frame-dependent. Reduced motion uses the measured waveform fallback.
- MP3 only. Moved/deleted files must be reimported from their new location. No named playlist manager exists.
- High-quality 4K feedback is GPU-intensive; choose Balanced/Economy if needed.

Third-party license notices ship under resources/app.asar (dist/licenses), plus Electron/Chromium notices alongside the executable. Full source and validation are in the repository.
