# SYNESTRA 1.0.1

Windows x64 installer release. Player and visualizer behavior is unchanged from 1.0.0: Classic Lightflow, Pearl, Spectrum and ten MilkDrop presets remain available.

## Install / launch

Download SYNESTRA-Setup-1.0.1-x64.exe from https://github.com/scryingorb/SYNESTRA/releases/tag/v1.0.1. Run it and follow the setup wizard. It installs for your Windows account, lets you choose a location, and creates Start menu / desktop shortcuts. Open SYNESTRA from a shortcut after setup. Node.js, npm and development tools are not required; Electron and all app assets are included. Windows 10/11 x64 is required.

The installer is unsigned. Windows may display an unknown-publisher or SmartScreen prompt; verify the source and published SHA-256 before deciding to run it. This is a full offline installer.

Import MP3 files, select a queue entry or press Play. Change visualizers in the header; Tune controls MilkDrop presets, transitions, cycling and graphics quality. Enter fullscreen expands the visual stage. Library references and valid settings persist without autoplay. Volume/mute does not weaken audio analysis.

## Update / uninstall

Close SYNESTRA before running setup. Existing 1.0.0 ZIP users can install this edition; the same AppData settings/library are reused. Remove an old ZIP folder only after closing its copy of the app. Source music stays in its original location.

Uninstall through Windows Settings > Apps > Installed apps > SYNESTRA, or the installed uninstaller. Uninstall removes application files and shortcuts but retains %APPDATA%\SYNESTRA settings/library. To reset those deliberately, delete that AppData folder after closing the app; source music is unaffected.

## Changes

- Added a per-user NSIS setup wizard, installation-location choice, shortcuts and uninstaller.
- Updated release/repository links to scryingorb/SYNESTRA.
- No player, analysis, preset, rendering-engine or dependency changes.

## Limitations

Unsigned Windows x64 build; no automatic updater. Clean-machine/another-PC testing, prolonged listening and sustained physical 4K/60 FPS remain pending. Existing actual 4K buffer measurements are not a performance guarantee. MilkDrop uses mono visual PCM and reduced motion falls back to waveform rendering. MP3 only; missing source files must be reimported. Third-party notices are installed in the licenses folder.
